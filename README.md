# Quantitative Finance Problems

Independent quantitative finance research and problem-solving projects using mathematical modelling, statistical analysis, and Python.

## Project 01: Portfolio Optimisation

**Research Question:** Can optimised portfolios outperform a simple equally weighted portfolio out of sample?

### Objectives
- Construct equal-weight and optimised portfolios.
- Investigate the impact of estimation error on portfolio performance.
- Conduct rolling out-of-sample backtesting.
- Evaluate risk-adjusted returns, drawdowns, and turnover.

### Data
Kenneth French Data Library — 10 Industry Portfolios.
